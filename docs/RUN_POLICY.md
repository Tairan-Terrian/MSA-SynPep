## 运行语义

每次正式运行属于一个明确的代码版本和配置。目录使用可读的版本与运行名称，例如 `results/v2_run01/`。启动前清空本项目原有 `results/`，创建本次空目录。整个流程从候选与结构输入准备开始。

| 内容 | 本次如何处理 |
|---|---|
| 原始公开 PDB、参考序列与已核查文献 | 作为原始研究依据读取 |
| 预训练权重和软件环境 | 作为固定计算工具使用 |
| 处理后的靶标、组装体和表面特征 | 本次重新准备与计算 |
| LLM 候选序列与 API 请求/响应 | 本次重新产生 |
| 结合姿势、结构优化与几何评价 | 本次重新计算 |
| 计算证据、LLM 排名、完整嵌合肽与模拟 | 本次重新计算 |
| 表格、图像与报告 | 根据本次实际结果生成 |
| 多轮设计反馈 | 使用本次实验早先阶段产生的观察 |

数据使用路径应能清楚区分原始研究输入与本次生成结果。`data/inputs` 中存量候选、坐标、上下文和来源记录属于旧实验生成缓存；新入口仅从原始输入和本次输出获取相应内容。

## 当前入口

`pipeline.py`直接清空本项目的results并建立本次目录，随后执行三个模块。每次正式运行重新生成候选、姿势、指标、排名、融合模型和轨迹。两个Top10输出100组肽对，比较600种连接方案；短模拟集中到最多20组，最终输出10条完整融合肽及独立复核。

```bash
.venv/bin/python pipeline.py --name bounded_20261013
```

凭据使用SYNPep_API_KEY环境变量配置。调用记录保存本次请求、返回和token用量。两块GPU分别执行姿势、结构与动力学任务。原始结构和参考统计数据位于data/，本次处理结构位于results/本次目录/inputs/。
