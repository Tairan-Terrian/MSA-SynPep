表面输入保留组装体遮挡、三/五层SASA、侧链方向/电荷/疏水描述、跨链口袋。Wallace文献为构象识别可行性依据，当前四区域的系统实验表位和突变标签保持缺失。其他蛋白纤维和所有正常状态的对照范围保持未知。
